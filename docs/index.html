Androidアプリ歩きスマホ注意 by usePocket

歩きながらスマホの画面を使うと、赤い警告とバイブで立ち止まるまでしつこく知らせます。警告した回数は端末内に記録され、保護者があとから日別・時間帯別に確認できます。子どもの歩きスマホ対策に作りました。

できること

しつこく警告

画面の上に点滅する赤い警告を重ね、数秒ごとにバイブ。歩き続けると全画面に広がります。

回数を長期保存

警告1回ごとに日時・長さ・歩数を記録。日別・時間帯別のグラフで、いつ多いかがわかります。

保護者の暗証番号

見守りの停止、判定の変更、履歴の消去には暗証番号が必要です。

止めた形跡も残る

強制停止などで見守りが5分以上止まっていた期間は、理由つきで履歴に残ります。

操作はふさがないので、警告中も地図や電話は使えます。通話中は警告しません。インターネットへの接続は一切せず、記録はスマホの中だけに保存されます。

警告の流れ

画面を見ながら歩くロックを解除した状態で5秒以上歩き続ける
警告が出る赤い警告が点滅し、3秒ごとにバイブ
全画面に広がる警告から10秒たっても歩き続けていると、画面いっぱいに
立ち止まると消える3秒止まるか、画面を消すと終了。1回として記録

歩いたあと立ち止まってから画面を開いた場合は警告しません。秒数はあとから設定で変えられます。

インストール

Google Playではなく、このページから直接インストールするアプリです。作業はお子さんのスマホで行います。

  1. APKをダウンロード

    お子さんのスマホで上の「APKをダウンロード」を押すか、PCに表示したQRコードを読み取ります。「このファイルは有害な可能性があります」と出たら「ダウンロード」を押します。

  2. ダウンロードしたファイルを開く

    通知の「ダウンロード完了」か、「Files」アプリの「ダウンロード」から arukisumaho.apk を開きます。

  3. 「提供元不明のアプリ」を許可

    「セキュリティ上の理由から…」と出たら「設定」を押し、使っているブラウザ（Chromeなど）の「この提供元のアプリを許可」をオンにして戻ります。

  4. インストール

    「インストール」を押します。Playプロテクトの確認が出たら「詳細」→「インストールする」（または「スキャンせずにインストール」）を選びます。

初期設定

アプリを開くと「必要な許可」の一覧が出ます。⚠️の付いた項目の「許可する」を順に押してください。

  • ① 身体活動歩数を数えるために使います。「許可」を選びます。
  • ② 他のアプリの上に重ねて表示警告を表示するために使います。一覧からこのアプリを選んでオンにします。
  • ③ 電池の最適化をしない裏で止められないようにします。「許可」を選びます。
  • ④ 通知Android 13以降のみ。「見守り中」の通知を出すために使います。
Android 13以降で②のスイッチが押せないとき ストア以外から入れたアプリは、この許可が「制限付き設定」で止められています。次の手順で解除してください（アプリ内にも同じ説明が出ます）。
  1. アプリの②「許可する」を一度押し、許可できない画面を出してから戻る
  2. アプリの「アプリ情報を開く」を押す（または 設定 → アプリ → 歩きスマホ注意by usePocket）
  3. 右上の「︙」→「制限付き設定を許可」を押し、指紋や画面ロックで確認
  4. アプリに戻り、②の「許可する」をもう一度押す
Android 11以前では、この手順は不要です。

見守りを開始する

  1. すべての許可が ✅ になったら「見守りを開始」を押します。
  2. 保護者用の暗証番号（4桁以上）を2回入力します。お子さんに知られない番号にしてください。
  3. 「● 見守り中」と表示され、通知欄に「歩きスマホ見守り中」が出れば完了です。再起動しても自動で再開します。

動作を試すときは、画面を見ながら5秒ほど歩いてみてください。

判定の調整

設定画面の「警告の判定」で変えられます。変更には暗証番号が必要で、すぐに反映されます。

項目選べる値初期値
警告を出すまで（画面を見ながら歩き続けた時間）3〜20秒5秒
警告を消すまで（立ち止まってから）2〜8秒3秒
警告中のバイブなし／2〜10秒ごと3秒ごと
警告を全画面に広げる広げない／5〜30秒後10秒後

警告が多すぎると感じたら、まず「警告を出すまで」を8秒や10秒に延ばしてみてください。

履歴を見る

設定画面の「警告の履歴を見る」から開きます。

  • 回数のまとめ：今日・7日間・30日間・累計の回数と、1日あたりの平均
  • 日別グラフ：最近30日の回数
  • 時間帯別グラフ：登下校の時間に多いかなど、いちばん多い時間帯もわかります
  • 警告の一覧：日時・長さ・歩数（新しい順に最大200件）
  • 見守りが止まっていた期間：電源オフ、強制停止など、保護者の停止を区別して表示。強制停止などは赤字になります
  • CSVで共有・保存：全件をメールやメモに送れます

記録はアンインストールしない限り残ります。「履歴をすべて消去」には暗証番号が必要です。

更新のしかた

新しいバージョンが出たら、このページから同じようにAPKをダウンロードして開き、「更新」を押すだけです。履歴・設定・暗証番号はそのまま残ります。アンインストールしてから入れ直すと履歴が消えるので注意してください。

注意点・よくある質問

子どもがアプリを止めたり消したりできませんか？

アプリ内での停止には暗証番号が要りますが、Androidの設定から強制停止やアンインストールをすることは防げません。強制停止された期間は履歴に赤字で残るので、確認の目安にしてください。確実に防ぎたい場合は、Googleファミリーリンクなどでアプリの削除を制限する方法と組み合わせてください。

電車やバスの中で警告が出ます

揺れを歩行と見分けられず、警告が出ることがあります。気になる場合は「警告を出すまで」の秒数を延ばしてください。

警告がまったく出ません

①〜③の許可がすべて ✅ になっているか、「● 見守り中」になっているかを確認してください。機種によっては、電池の節約機能でアプリが止められることがあります。その場合は 設定 → アプリ → 歩きスマホ注意 → 電池 で「制限なし」にしてください。

暗証番号を忘れました

暗証番号を確認・再設定する方法はありません。アンインストールして入れ直せば使えますが、それまでの履歴は消えます。

個人情報は送信されますか？

送信しません。このアプリはインターネットに接続する権限を持っておらず、記録はスマホの中だけに保存されます。

電池の減りは？

歩数センサーのある機種では、歩数の検出はスマホ側の省電力な仕組みで行うため、影響はわずかです。歩数センサーのない機種では画面がついている間だけ加速度センサーを使います。

iPhoneでは使えますか？

Android専用です。Android 8.0以上で動きます（Android 11・17で動作を確認しています）。
